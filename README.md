<h2><a class="anchor" id="overview"></a>Overview</h2>

Nova is a modern, responsive e-commerce website developed using React.js, JavaScript, HTML5, and CSS3. The website provides users with a smooth online shopping experience through an attractive interface and easy navigation.

It includes product categories, collections, sale sections, special deals, product details, and shopping cart functionality. Users can browse products, add items to their shopping bag, manage quantities, and proceed to checkout.

---
<h2><a class="anchor" id="business-problem"></a>Business Problem</h2>

In today's digital world, customers prefer convenient and user-friendly online shopping platforms. Traditional shopping can require more time and effort to explore different products and compare prices.

Nova aims to address these challenges by providing:
- A simple and attractive online shopping interface.
- Easy product browsing through categories and collections.
- Quick access to special offers, deals, and discounted products.
- Shopping cart functionality to manage selected products.
- Responsive design for desktop, tablet, and mobile devices.

---
<h2><a class="anchor" id="tools--technologies"></a>Tools & Technologies</h2>

- React.js: Used to build reusable components and create the user interface.
- JavaScript: Used to implement interactive functionality and shopping cart operations.
- HTML5: Used to structure the website content.
- CSS3: Used for styling, layouts, animations, and responsive design.
- Vite: Used as the development server and build tool.
- Local Storage: Used to preserve shopping cart data in the browser.
- VS Code: Used as the code editor.

<h2><a class="anchor" id="how-to-run-this-project"></a>How to Run This Project</h2>

1. Clone the repository:
```bash
git clone https://github.com/mulanitanveer28/Nova_Ecommerce_Website_React.js.git
```

2.  Install Node.js

3. Extract the Project

4.  Open the Project

5. Open the Terminal

6. Install Dependencies

```
npm install

```

7. Start the Development Server

```
npm run dev

```

8. Open the Website
Open the local URL displayed in your terminal, usually:

```
http://localhost:5173/

```
The Nova e-commerce website will now be running locally.
